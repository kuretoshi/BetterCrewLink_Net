# TanukiBCL.Net v3.2.8-net-beta.2

タヌキのベタクル v3.2.8 を .NET/WPF に移植中の、Windows x64 向けプレリリースです。完全互換を宣言する版ではありません。

## beta.1からの変更

- インストーラー版をアプリ内更新したあともWindowsのアンインストーラーが残るよう、更新ZIPにインストーラーと同じ `Uninstall.exe` を同梱しました。
- 公開済みbeta.1の更新補助ツールによる545ファイルの入れ替え、更新ZIPの検証・展開、隔離フォルダーへのインストールとアンインストールを確認しました。
- 公開リリースを実際に検出し、ZIPをダウンロードしてサイズ・SHA-256・内容を検証できることを確認しました。更新画面からの終了・入れ替え・再起動を通した試験と、新規Windows環境での起動確認は継続します。

通常は `TanukiBCL.Net-Setup-3.2.8-net-beta.2.exe` を使ってください。持ち運び用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーはデジタル署名されていません。ベータ版に含まれる開発者デバッグ画面は、配布者が設定した共通パスワードで保護されています。

beta.1からアプリ内更新が完了した場合、Windowsのアプリ一覧に表示される版はbeta.1のまま残る可能性があります。更新処理はアプリとアンインストーラーをbeta.2に入れ替えますが、表示上の版の同期は次版で修正予定です。

公式3.2.8との主要な双方向音声・距離・会議・生死・ラジオ等は検証済みですが、追加役職、細部のGUI、環境差を含む完全互換は引き続きベータテスト中です。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。パスワードやロビーの秘密情報は添付しないでください。
