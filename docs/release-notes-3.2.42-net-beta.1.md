# TanukiBCL.Net 3.2.42 β1

公式タヌキのベタクル3.2.42に合わせたWindows x64向けベータ・プレリリースです。

- NoSのボイスジャミンガー・メガホン・ビビリの強さ設定を、タヌキ丼アドオンの検出時だけ表示します。
- NoSとSNRのボイスエフェクト項目は、それぞれのMOD検出時に表示します。
- シトラスと虹色スターはUchuAddonの検出時に表示します。
- 有効／無効はロビー設定へ戻し、強さはホストがゲーム中にも変更できるようにしました。
- Releaseビルドと設定画面の自己テストを実施しました。実ゲームでの確認はベータテスト対象です。

通常は `TanukiBCL.Net-Setup-3.2.42-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
