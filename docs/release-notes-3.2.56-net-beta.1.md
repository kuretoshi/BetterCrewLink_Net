# TanukiBCL.Net 3.2.56 β1

- 一般設定に「画面レイアウト」を追加しました。「デフォルト」と「生存者・霊界を分ける」を切り替えられます。会議前の未公開の死亡情報は表示しません。
- インストール時にデスクトップショートカットの作成を選択できます。初期状態はオフです。
- NoSのタヌキ丼（tanuki.bcl.roles）を検出している間だけ、追加役職の状態ファイル読み取り、マイク連携、音声認識を有効にします。
- NoS役職の定期読み取りを、ゲームプロセス全体のスナップショットから非停止の直接読み取りへ変更しました。

画面・設定保存・音声ルール・UDP通信の回帰テストを実施しています。報告されたゲームの周期的な停止が解消するかは、実際のゲーム環境での確認が必要です。
