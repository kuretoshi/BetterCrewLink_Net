# TanukiBCL.Net v3.2.8-net-beta.3

タヌキのベタクル v3.2.8 を.NET/WPFへ移植中の、Windows x64向けプレリリースです。完全互換版ではありません。

## beta.2からの変更

- インストール版をアプリ内更新した後、Windowsのアプリ一覧に表示されるバージョンと名前を、新しい版に同期します。登録済みのインストール先とアンインストーラーが一致する場合だけ更新します。
- アプリ内更新に成功した後、ダウンロード済みZIPと展開済みの一時ペイロードを削除します。更新前のバックアップは残します。

通常は `TanukiBCL.Net-Setup-3.2.8-net-beta.3.exe` を使用してください。持ち運び用とアプリ内更新用に `TanukiBCL.Net-win-x64.zip` もあります。インストーラーはデジタル署名されていません。開発者デバッグ画面は配布者が設定した共通パスワードで保護されています。

公式3.2.8との主要な双方向通話・距離・会議・生死・ラジオ等は実機検証済みですが、追加役職、細部のGUI、環境ごとの再接続などは引き続きベータテスト中です。新規Windows環境での起動と、公開版同士のアプリ内更新の画面操作から再起動までの一連の検証も未完了です。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。パスワードやロビーの秘密情報は添付しないでください。
