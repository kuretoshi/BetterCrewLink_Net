## インタビュアーの録音・会議中再生に対応

タヌキ丼の新役職「インタビュアー」に対応しました。自分と視界内の生存者の声を録音し、会議中に全員へ再生できます。

録音途中の会議は部分保存し、再録音で上書きします。試合終了・役職解除・切断時には録音を破棄します。.NET版をホストにしたWeb・モバイル参加者への役職状態の中継にも対応しました。

**タヌキ丼 0.1.0-β11** と合わせてご利用ください。Web・モバイル版は **3.28以降**が対応版です。

Windows x64向け.NETベータ版です。録音・再生処理は自動テストで確認していますが、実際の複数人のマイクを使った通話試験は未実施です。
