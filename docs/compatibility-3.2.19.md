# TanukiBCL v3.2.18–3.2.19 互換チェック

基準は公式 `v3.2.19` (`7a9e2ca1a2024826aa8a4a2119468a1ccf664a17`)。.NET版は利用者の要望に従い、Among Usの64bitプロセスのみを対象とする。

| 公式での変更 | .NET版 |
| --- | --- |
| TOH4E系の役職一覧・CustomRoleTypeをロード済みDLLのAllRolesInfoから取得 | 同じレジストリを補助リーダーで読み、RoleId・表示名・陣営・IKillerを検証。既存の役職・キラー読取へ反映。 |
| インポスター判定を本体フラグとDLL陣営の両方で行う | 公式と同じAND判定。ホストは役職情報、参加者は役職本人向け報告と役職名を含まない陣営フラグを使用。情報が未取得・期限切れならTOHのインポスター権限は付与しない。 |
| キル可能な第三陣営・アニマルズ役職の幽霊音声設定 | 取得した役職一覧から自動生成。役職個別および陣営一括のON/OFF、件数表示、参加者の閲覧専用表示に対応。旧設定は明示的な役職設定がまだない場合の既定値として維持。 |
| ロビーから役職一覧・設定を同期 | ホストはTOHロビー報告に一覧を添付。通常のロビー設定メッセージで個別設定を同期。ホストの切断・交代・受信期限切れで一覧を消去する。 |
| 32bit/64bit対応 | .NET版の64bit対象方針を維持。32bit版は対象外。 |
| デバッグの陣営情報 | CustomRoleTypeとTOHインポスターフラグを表示。 |

確認: Releaseビルド、C#全体の制御構文ネスト3段以内、音声ポリシー・設定画面の自己テストを実施。起動中のTOH4E_EM実プロセスから149役職を取得し、第三陣営のキラー16・アニマルズのキラー7を確認した。公式3.2.19との複数人通話および実ゲームでの設定同期は未確認であり、βフィードバック対象。
