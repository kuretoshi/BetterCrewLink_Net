# TanukiBCL 3.2.32 互換チェックリスト

公式リリース: https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.32
OBSブラウザソース: https://github.com/kuretoshi/BetterCrewlink-obs_fix/releases/tag/v3.2.32

## 反映内容

- 音声ゲートの終了時に20 msのテーパーを適用。ミュート・PTTは即時に無音化。自動ゲイン制御中は手動ゲインと独立の感度ゲートを適用しない。
- OBS状態通知に`assetSession`と、SNR/NoSのスキン・NoSボディマスク画像ソースを追加。ブラウザソースの`obs-cosmetics-request`に、現ロビーで許可した画像だけを512 KiB以下のPNGデータURLで応答。8 MiBのキャッシュ上限、4件の同時処理上限、ロビー切替時の破棄を設けた。OBS再読込後にも通知が届くよう、状態が同一でも5秒で再送。
- TOH4E/TOH4E_EMの役職一覧通知を変更時または3秒ごと、個別役職通知を3秒ごとに削減。名簿は変更時・新規peer参加時のみ送信する。
- Electron版のマイク切替競合は、.NET版では旧セッションの終了後にキャプチャを再生成する既存構造のため同じ非同期競合経路を持たない。名前が同じ複数のWinMMマイクを選んだ場合も選択IDを保持し、設定画面と再接続時に同じデバイスを優先する。選択デバイスの実機録音は未確認。
