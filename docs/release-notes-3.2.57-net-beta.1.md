# TanukiBCL.Net 3.2.57 β1

- 管理者用BAN画面で、プレイヤー識別子（UID）とグローバルIPを選択できるようにしました。登録済みBANは種別ごとに個別に解除できます。
- プレイヤー履歴に、本人の接続で確認したグローバルIPとUID・IPそれぞれのBAN状態を表示します。IP未確認の履歴ではIP BANを選択できません。IP BANは同じ回線の他のプレイヤーも対象になります。
- IP BANに未対応のサーバーではUID管理を継続できます。IP操作が失敗した場合にUID BANへ切り替えることはありません。
- NoSの役職名は、その場にいる役職に必要な翻訳だけを読み取るようにしました。言語の優先順位と読み取り中の変更検出を維持し、不要な読み取りを減らしています。

グローバルIPはBANサーバーが接続元から取得します。アプリが他のプレイヤーのIPを推測・送信することはありません。報告されたゲームの周期的な停止が解消するかは、実際のゲーム環境での確認が必要です。
