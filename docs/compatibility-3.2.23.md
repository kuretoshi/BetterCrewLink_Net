# TanukiBCL v3.2.23 互換チェック

基準は公式 [`v3.2.23`](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.23) (`eb9089b982bcdca1f7f25743f0374c149e6dc137`)。.NET版は64bit版Among Usのみ対象とする。β版は `3.2.23-net-beta.1`。

| 公式での変更 | .NET版での対応 |
| --- | --- |
| Airshipメインホールなどでスポーン座標のXまたはYが0のとき、未取得座標として扱わない | .NETのメモリリーダーは既に有限の座標0をそのまま保持しており、`Bugged`判定も0を除外しない。Airshipの座標(0, 0)と(0, 0.5)で音声が届く回帰テストを追加。 |
| 64bit版SNRの役職・Jumbo現在／最大サイズを取得する | 64bit補助リーダーのライブレイアウト生成からcollectible型の一律拒否を撤去。既存の64bitポインター／32bit配列長・リスト件数読取を、4GB超のアドレス、配列の8バイト間隔、リスト件数の隣のversion値、Jumboのサイズで検証。32bit版は対応対象外。 |

Releaseビルド、SNRライブ読取の合成回帰、音声ポリシー、ゲームスキャン、設定、およびC#全147ファイルのネスト上限3段検査は通過。公式3.2.23との実音声、Airship実マップ上の座標0での通話、64bit SNR実プロセスからの役職・Jumboサイズ取得は未確認で、βテスト対象とする。
