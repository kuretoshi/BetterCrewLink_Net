SNR衣装表示の安定性を改善しました。

- 圧縮された衣装画像の透明な余白を復元し、大きさと位置を修正しました。
- ロビーでもハット2・バイザー2を読み取り、衣装の切り替え・取り外しを反映します。
- 衣装ごとの色連動設定を優先し、プレイヤーの色に追従します。固定色の衣装と透明度は維持します。
- 一時的に読み込めなかった衣装画像を再試行し、表示を復帰します。
- Web・モバイル参加者にも、色を反映した主衣装と追加衣装の画像を送ります。

通常版・Lite版3.2.71、Tauri版3.2.71、Web・モバイル版3.69と表示仕様を揃えました。.NET版は引き続きプレリリースです。

衣装画像の全画素比較、ロビーの追加衣装読み取り、色と透明度、再試行、モバイルへの画像送信を自動検証しています。
