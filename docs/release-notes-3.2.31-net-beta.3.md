# TanukiBCL.Net 3.2.31 β3

アバター一覧の自動サイズ調整と設定画面の更新負荷削減を含む、Windows x64向けベータ・プレリリースです。

- ベタクル画面のアバター一覧を、人数と表示領域の縦横サイズに応じて自動調整し、スクロールせず全員を確認できるようにしました。ウィンドウのサイズ変更やバージョン通知の表示・非表示にも追従します。
- 設定画面の「現在のロビー」で、ゲーム状態の更新ごとに多数の設定項目を再読込する処理を削減しました。サーバーからの設定変更、ロビー復帰、編集可否の切替は引き続き反映します。
- 20人表示・サイズ変更・通知表示時のレイアウト、設定の連続更新と変更反映を自己テストで確認しました。スクロールの体感改善と実ロビーでの目視確認はベータテスト対象です。

通常は `TanukiBCL.Net-Setup-3.2.31-net-beta.3.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
