# TanukiBCL 3.2.31 互換チェックリスト

公式リリース: https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.31

## 反映

- バージョン不一致通知をプレイヤー一覧を押し下げるヘッダーから外し、フッター上の独立した表示領域へ移動。
- 長文通知は高さ96pxを上限に領域内でスクロール。通知表示中は一覧の下に104pxの余白を確保し、プレイヤーと通知が重ならないようにした。
- エラー画面では通知を隠し、復帰すると再表示する。
- 音声・ゲーム読取・通信プロトコルは3.2.30から変更なし。

## 確認

- WPF自己テストで、通知表示・解除時にヘッダーとフッター位置が動かないこと、一覧の余白、長文スクロール、エラー画面との排他を確認。
- Release/x64ビルド、ネスト深さ上限3、配布ZIP・インストーラーと展開ZIPからの起動を確認。
- 実ロビーでの目視比較は引き続きベータフィードバック対象。
