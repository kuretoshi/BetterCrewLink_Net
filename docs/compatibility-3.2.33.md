# TanukiBCL 3.2.33 互換チェックリスト

公式リリース: https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.33

## 反映内容

- 公式版で保存済みのマイクIDが使えないときに既定マイクで再試行する修正を確認。TanukiBCL.NetはWinMMのデバイスIDと名前を保存し、IDが消えた場合は同名の利用可能なマイク、次に最初の利用可能なマイクを選ぶ既存処理で対応している。
- 3.2.32の音声、OBS、TOH4E関連の互換処理を維持。

## 確認状況

- マイク選択の自己テストでは、ID一致、ID消失時の同名選択、マイク名も消失した場合の利用可能なデバイス選択を確認。
- 実機でのマイク抜き差しと再接続は未確認。ベータテストで確認する。
