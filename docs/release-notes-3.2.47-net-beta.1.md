# TanukiBCL.Net 3.2.47 β1

- タヌキ丼0.1.0-β16のヒーロー2役職と「NGワード」の音声認識に対応しました。
- 自分のマイクは自分のPCで認識し、ホストはWeb・モバイル参加者の声を追加で認識します。日本語モデルを同梱し、外部の音声認識サービスは使用しません。
- ヒーローの変身衣装によるボイスエフェクトを除外しました。他の能力による音声妨害は通常どおり適用します。
- PC通常版・Lite版3.2.47、Web・モバイル版3.39との連携に対応します。

.NET版は引き続きプレリリースです。認識の分担・判定処理の自己テストとビルドは通過していますが、新機能の複数端末での実音声・負荷は未検証です。
