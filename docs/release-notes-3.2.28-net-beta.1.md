# TanukiBCL.Net 3.2.28 β1

公式[タヌキのベタクル3.2.28](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.28)の問い合わせ変更を.NET/WPF版に取り込んだ、Windows x64向けベータ・プレリリースです。

- アプリ内の問い合わせを、[BetterCrewLink_Netの公開Issue](https://github.com/kuretoshi/BetterCrewLink_Net/issues)として作成し、.NET版のDiscordフォーラムへ転送します。Discord側の返信・編集・削除・件名変更は対応Issueへ反映されます。
- 送信前に、件名・本文・選択した添付ファイル・自動添付ログが公開されることを表示し、確認チェックを必須にしました。送信後は作成されたIssueを開けます。
- 本家版のIssueは使用しません。旧版クライアントの問い合わせは従来どおりDiscord直送です。

通常は `TanukiBCL.Net-Setup-3.2.28-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用ZIPもあります。インストーラーは未署名です。報告を送る前に、ログや添付ファイルにパスワード、ロビーコード、個人情報などが含まれていないか確認してください。
