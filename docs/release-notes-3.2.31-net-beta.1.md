# TanukiBCL.Net 3.2.31 β1

公式[タヌキのベタクル3.2.31](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.31)のバージョン不一致通知の配置修正を.NET/WPF版へ移植した、Windows x64向けベータ・プレリリースです。

- 通知をフッター上の独立した領域へ移し、プレイヤー表示を押し下げないようにしました。
- 長い通知は領域内でスクロールできます。エラー画面では通知を隠し、復帰すると再表示します。
- WPF自己テストでレイアウト・スクロール・エラー画面を検証しました。実ロビーでの目視確認はベータテスト対象です。

通常は `TanukiBCL.Net-Setup-3.2.31-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用ZIPもあります。インストーラーは未署名です。
