# 3.2.7 お問い合わせ画面

公式release `9861ccc8137bb63a7d3834f493be0b784a288544` の `InquiryButton.tsx`、`InquiryWindow.tsx`、`ipc-handlers.ts` を基準に、メイン画面の「お問い合わせ」ボタンを診断画面への誤配線から専用フォームへ変更した。質問/不具合/要望、件名100文字、本文1800文字、複数添付の追加・削除、送信中の入力停止、成功/失敗表示を実装した。

送信は公式と同じDiscordフォーラムWebhookとタグID、`wait=true`、`allowed_mentions.parse=[]`、添付合計24MiB制限を使用する。`.NET`側のサポートログが存在する場合は最後の1MiBを自動添付する。ログ自動添付は画面で明示する。ログの常時ファイル出力はまだ移植していないため、通常は添付されない。実Discordへの投稿は行っていない。
