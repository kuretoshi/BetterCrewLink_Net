共有モデル（Silero VAD＋SenseVoice）を変身ワード・NGワード・ボイスストーンに共通で使用するようにしました。PCは各自、Web・モバイル参加者の分はPCホストが認識します。モデル未準備・Offの場合は従来の軽量方式を使用し、タヌキ丼未検出時は読み込みません。

- ボイスエフェクトとロビーのスライダー、詳細設定の音声認識カードを通常版に揃えました。音声認識は詳細設定の下に配置します。
- 問い合わせの確認チェックを送信ボタンの上に移し、本文・添付ボタンの見切れと入力文字の欠けを修正しました。
- デバッグ版に認証設定がない場合も、通常版と同じHTTPS認証サーバーを使用します。
- Visual C++ v14 Redistributable（x64）が不足している場合は公式ページを案内します。

通常版3.2.70、Web・モバイル版3.68、タヌキ丼β24に対応します。共有モデル導入済みの場合は再導入不要です。音声認識APIキーは不要です。

ビルド・設定/認証/問い合わせテスト・描画・合成音声による認識を確認しています。物理マイクと多人数の実試合は未確認です。
