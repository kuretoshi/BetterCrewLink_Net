# TanukiBCL v3.2.22 互換チェック

基準は公式 [`v3.2.22`](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.22) (`196b4e0e222bc69422cb280db349985b2e4e14c0`)。.NET版は64bit版Among Usのみ対象とする。β版は `3.2.22-net-beta.1`。

| 公式での変更 | .NET版での対応 |
| --- | --- |
| NoSデータ未取得のままロビーから試合へ移った時、取得位置の再試行待ちを引き継がない | 読取セッションの切替で再試行待ちを解除し、試合開始後すぐに読み取り位置を再取得する。 |
| 読取位置取得の失敗後、再試行を1〜3秒へ短縮 | 1秒、2秒、以後は最大3秒のバックオフに変更。新しいセッションでは1秒から再開する。 |

時刻を制御した自己テストで、期限直前・期限到達・ロビーから試合への即時再試行・3秒上限を確認した。現在起動中のNoSプロセス1件では `TBCLFields.nextIndex` の読取位置を解決できず、ライブ診断は30秒でタイムアウトした。この状態での試合開始による復帰は未確認。3.2.21で追加した音声効果の聴感と公式版との双方向通話も引き続き未確認。
