# TanukiBCL.Net 3.2.32 β1

公式タヌキのベタクル3.2.32の変更を取り込んだ、Windows x64向けベータ・プレリリースです。

- 選択したマイクのデバイスIDを設定変更・再接続時にも保持し、同名のマイクを取り違えにくくしました。音声ゲートの終端に20 msの緩和を加え、AGC使用時の感度ゲートも公式版に合わせました。
- OBSブラウザソース向けにSNR/NoSのスキンとNoSのボディマスク画像ソースを追加しました。現ロビーで許可した画像のみを転送し、サイズ・キャッシュ・同時処理数を制限しています。
- TOH4E/TOH4E_EMの役職・ロビー通知を間引き、名簿を変更時または新規参加時に送るようにして通信量を抑えました。
- Releaseビルド、関連する自己テスト、更新ZIPの検証、C#のネスト深さ3以下を確認しました。実マイク切替、OBSでの画像表示、TOH4E実戦での通信量と遅延は未検証のため、ベータテストで確認します。

通常は `TanukiBCL.Net-Setup-3.2.32-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
