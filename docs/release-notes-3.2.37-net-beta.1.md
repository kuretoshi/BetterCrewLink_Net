# TanukiBCL.Net 3.2.37 β1

公式タヌキのベタクル3.2.37に合わせたWindows x64向けベータ・プレリリースです。

- NoSで「視界内のプレイヤーの声だけが聞こえる」がONのとき、第三陣営の広い視界半径が通話距離にも適用される問題を修正しました。第三陣営の通常会話はロビー設定の音声距離に従います。
- クルーの視界連動、インポスターの固定距離、他MODの距離判定、ラジオなどの専用音声は従来どおりです。
- Airshipのアーカイブ―コックピット相当の遠距離と近距離を含む自己テスト、Releaseビルド、ネスト深さ3以下、更新ZIPの検証を行いました。実ゲームでの通話確認はベータテスト対象です。

通常は `TanukiBCL.Net-Setup-3.2.37-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
