# TanukiBCL.Net 3.2.33 β1

公式タヌキのベタクル3.2.33に対応する、Windows x64向けベータ・プレリリースです。

- 公式版の保存済みマイクIDが無効になった場合の起動エラーに対応する処理は、.NET版では既存のデバイス再選択処理で実装済みです。IDが使えない場合は同名マイク、次に利用可能なマイクを選びます。
- マイク選択の自己テストを確認しました。実機でのマイク抜き差しは未確認です。

通常は `TanukiBCL.Net-Setup-3.2.33-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
