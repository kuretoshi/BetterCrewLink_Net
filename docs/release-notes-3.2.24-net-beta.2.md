# TanukiBCL.Net v3.2.24-net-beta.2

Windows x64向けベータ・プレリリースです。公式[タヌキのベタクル v3.2.24](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.24)を基準とし、β1から次を修正しました。

- Among Usを検出してゲームのメニューにいるとき、起動待ち画面ではなく公式版と同じ「メニュー」と「公開ロビー」を表示します。ロビー参加・ゲーム終了後の表示切替も確認済みです。
- Among Usが開いている間、別のウィンドウをクリックしてもオーバーレイをゲーム上に保ち、別ウィンドウより前には重ねないようにしました。

β1で取り込んだNoS役職音声連携、SNR落下中の音声、Web・モバイルの声量中継などは継続して含まれます。公式3.2.24との実音声の双方向通話、新しい役職効果の聴感、Mobile 3.13との実通信、SNR落下中の生体データ読取、NoS画像転送のWeb実機表示は未確認で、引き続きβテスト対象です。

通常は`TanukiBCL.Net-Setup-3.2.24-net-beta.2.exe`を使用してください。持ち運び・アプリ内更新用ZIPもあります。インストーラーは未署名です。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。
