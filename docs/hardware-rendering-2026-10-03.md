# ハードウェアアクセラレーション設定

TanukiBCL v3.2.7 (`9861ccc8137bb63a7d3834f493be0b784a288544`) のAdvancedSectionの操作に合わせ、詳細設定へスイッチを追加した。既定はON。OFFへの変更時のみ警告し、キャンセルでは元の値を維持する。

起動時にWPFの `RenderOptions.ProcessRenderMode` をONならDefault、OFFならSoftwareOnlyへ設定する。DefaultはWPFの自動選択であり、GPU利用を保証するものではない。Windowsのレジストリやシステム設定は変更しない。

設定変更は保存後に設定画面を閉じ、既存の終了経路で音声・ソケット処理を完了してから同じ実行パスを再起動する。未保存設定の書込失敗で閉じられなかった場合は再起動せず、エラー表示を維持する。接続中の場合、選択したゲームPIDを新プロセスへ渡す。再起動に失敗した場合は手動起動を案内する。

Releaseビルドは警告・エラー0。設定画面の確認・キャンセル、OFF保存、ONは警告なし、apphostとdotnetホストの起動引数、既存の設定トランザクション・セッション終了テストが成功した。テストは偽の保存先を使用し、ユーザーの設定を変更せず、新プロセスの実起動も行わない。

実GUIからのプロセス再起動とGPU/ソフトウェア描画比較は未検証。起動中の `publish/nos-colors-20261003` にはまだこの変更は含まれない。次の更新は許可済みの同一実行パスを利用する運用とし、新しいディレクトリを毎回起動先にしない。
