# TanukiBCL.Net v3.2.8-net-beta.4

タヌキのベタクル v3.2.8 を.NET/WPFへ移植中の、Windows x64向けプレリリースです。完全互換版ではありません。

## beta.3からの変更

- 配布版の通常起動で開発者用の「接続開始」診断画面を表示しないようにしました。ゲームを検出すると自動接続し、まだ起動していなければコンパクト画面で待機します。
- Among Usを複数起動している場合は、公式版と同様に最小PIDを選びます。開発検証で別のプロセスを指定するときは `--game-process-id <PID>` を使えます。
- 接続設定の反映エラーは通常画面に表示します。開発用診断画面のショートカットはDebugビルドに限り、配布版のデバッグ情報は従来どおり設定画面から共通パスワードで開きます。

通常は `TanukiBCL.Net-Setup-3.2.8-net-beta.4.exe` を使用してください。持ち運び用とアプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーはデジタル署名されていません。

公式3.2.8との主要な双方向通話・距離・会議・生死・ラジオ等は実機検証済みですが、追加役職、細部のGUI、環境ごとの再接続などは引き続きベータテスト中です。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。パスワードやロビーの秘密情報は添付しないでください。
