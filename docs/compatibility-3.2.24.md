# TanukiBCL v3.2.24 互換チェック

基準は公式 [`v3.2.24`](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.24) (`f714e33b8d5c8621a6045b94047481bc04887199`)。.NET版は64bit版Among Usのみ対象とする。β版は `3.2.24-net-beta.2`。

| 公式での変更 | .NET版での対応 |
| --- | --- |
| SNRで押し出されて落下中の会話と残響 | SNR補助リーダーへ生存中の落下アニメーション監視を追加。取得値が500msを超えたら破棄し、落下前の位置で生存者として音声判定、受信側に残響を付ける。落下終了または会議では元の生死判定へ戻す。 |
| タヌキ丼のビビリ・おしゃべり・マイクテストへのマイク声量送信 | NoSの役職ディスクリプターを検証し、50ms間隔のRMSとマイク有効状態を127.0.0.1のUDPへ送る。ディスカバリー応答と公開ファイルの両方を参照し、PID・PlayerId・ロール・トークン・場面を照合する。 |
| メガホンレーザー・携帯メガホン | NoS公開ファイルのPID・時刻・数値範囲を検証。レーザー蓄積による距離拡大・端のフェード・音声加工ON/OFFを音声ミックスへ反映し、携帯メガホンの追加距離を通常近接通話に加える。 |
| ビビリ自滅・メガホン中死亡時の残響 | NoSの死亡イベントから直前の受信音声を短いメモリ内遅延で減衰再生。ミュート・聴覚ミュート・場面変更で停止する。録音ファイルは作らない。 |
| Web・モバイルの声量をホスト経由でNoSへ送るベータ機能 | Socket.IOシグナリングの送信者・PlayerId・ClientId・ロビーを照合し、再送・過剰頻度を拒否。ホストPCのNoSディスクリプターのトークンとPIDで認証した127.0.0.1 UDPへ中継する。追加の証明書や接続コードは使わない。 |

Releaseビルド、役職状態ファイルの鮮度・不正入力、メガホン音声ルール、ビビリ残響、SNR落下中・落下終了の音声判定、Web・モバイル送信者照合、NoS向けUDPループバック送信、既存の音声ポリシー、C#全ファイルのネスト上限3段検査を通過した。実ゲームのタヌキ丼0.8.0 Build37以降やMobile 3.13との組み合わせ、SNRの実落下中の聴感は未確認で、βテスト対象とする。
