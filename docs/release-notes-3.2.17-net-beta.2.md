# TanukiBCL.Net v3.2.17-net-beta.2

Windows x64向けのベータ・プレリリースです。公式[タヌキのベタクル v3.2.17](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.17)に対応したβ1から、次を更新しました。

- 設定画面を最大化した際、「問い合わせ」フォームを公式版に近い幅で中央に配置するよう修正しました。通常幅では画面内に収めます。
- NoSローカルロビーで公式版と.NET版の2～4人表示、フッター、相互の接続表示を実画面で確認しました。C#全体のネスト上限3段も維持しています。

ビルド、設定・問い合わせの自己テスト、幅500/1800pxのレイアウト検査を通過しました。公式3.2.17との実音声の双方向通話は、テスト時に発話できなかったため未確認です。公式版のNoSメモリ読取エラーも見られたため、試合中の距離・役職連動は未確認です。

通常は `TanukiBCL.Net-Setup-3.2.17-net-beta.2.exe` を使用してください。持ち運び用とアプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーはデジタル署名されていません。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。
