# コスメティック移植の進捗

基準: v3.2.7 `9861ccc8137bb63a7d3834f493be0b784a288544` の `renderer/lib/cosmetics.ts` と `components/Avatar.tsx`。

`CosmeticCatalog` に共有hats.jsonの読取・画像選択を移植した。IDは大文字小文字を区別し、NONE定義をMOD定義より優先する。前／後画像、項目固有の配置とグループ既定値、multi_colorフラグ、%/px配置値を扱う。カタログ由来のURLは既存配信元の対応グループ内に制限する。

検証:

- Releaseビルド、`--cosmetics-self-test` は終了0。IDの大文字小文字、NONE優先、MODフォールバック、後画像、欠落画像、不正相対パス、配置値を検証。
- `--cosmetics-self-test --download-cosmetics-catalog` は実際の3.2.7と同じ配信元からカタログを取得し、5グループ・3421件の前後画像指定を解決した。全解決画像の配置値もパースできた。画像ファイル自体の全件ダウンロードや描画検証ではない。

このコミットは画像選択の基盤であり、コスメティック表示完了ではない。次に画像の非同期読込、体色連動、前後関係、死亡時非表示、アバタークリップとオーバーフロー、変装・追加帽子を接続する。SNRのリモート定義／ローカル画像と固有配置も別途必要。起動中の.NET画面にはこの基盤をまだ接続していない。
