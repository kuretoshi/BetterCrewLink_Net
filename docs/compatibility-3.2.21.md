# TanukiBCL v3.2.21 互換チェック

基準は公式 [`v3.2.21`](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.21) (`3b07ee3fa290cc6eff9ecf5c4403579f849ded03`)。.NET版は64bit版Among Usのみ対象とする。この変更は `3.2.21-netdev.0` で実装し、`3.2.22-net-beta.1` に含めて配布した。

| 公式での変更 | .NET版での対応 |
| --- | --- |
| NoS v3.5.3.6のTBCLFields `20261009`、`BodyType`・`NeckLength` | 補助リーダーとスナップショットのレイアウト、値の検証、旧スキーマとの共存に対応。 |
| NoS役職・能力の読み取り | 役職、バーサーカー状態、虹色スターを約2秒間隔で取得。プロセス・ラウンドの切替時と期限切れ時は破棄。デバッグ画面に状態と役職情報を表示。 |
| サイズ変化とSNR Jumboの新しいsource-filter音声処理 | 2048点STFT・512点ホップ、ケプストラム包絡、ピッチ／フォルマントの独立変換、連続スクワッシュを移植。 |
| ろくろ首、バーサーカー、シトラス、虹色スター | 新しい音声選択条件と音声処理を追加。シトラスと虹色スターの設定は`UchuAddon`検出時のみ表示し、会議中の効果も維持。バーサーカーの短い残響は低コストなタップ近似で、公式のノイズ・インパルス畳み込みとは厳密一致しない。 |
| フィクサー妨害の1200Hzローパス | 妨害側・受信側の両方に適用。音声遮断との排他的な設定UIを追加。 |
| ロビー設定同期 | 追加された5項目を公式と同じJSON名・既定値で同期。日本語・英語ラベルを追加。 |

Releaseビルド、NoSスナップショット、音声ポリシー、設定・デバッグUI、全C#ソースのネスト上限3段検査を実行する。起動中のNoSプロセスで `20261009` レイアウト、`BodyType=0`・`NeckLength=0`、バーサーカーの役職名とネイティブ状態のレイアウト取得を確認した。ゲームリーダーを通して役職1件と `UchuAddon` 検出も確認。バーサーカー発動中の読み取り、複数人の双方向音声、各音声効果の聴感は未確認。したがって3.2.21との完全互換を実機で保証した段階ではない。
