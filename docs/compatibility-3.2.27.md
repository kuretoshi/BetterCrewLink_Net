# TanukiBCL 3.2.27 互換チェックリスト

公式リリース: https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.27

## 反映

- SNRローカルカスタムスキン: 公式のフォールバック位置（上 `-52%`、左 `-18px`、幅 `140%`）を維持し、描画回帰テストを追加。
- NoSラジオ: 押下中にラジオ定義が一時的に欠けた場合、押下状態を保持して送信を保留。保留中はマイク音声と発話表示を抑制し、定義復帰でラジオ送信を再開。キー解除・死亡・試合外では保留を解除。
- 管理画面・通信プロトコルの変更はなし。

## 確認

- .NET Releaseビルド、ポリシー自己テスト、SNRローカル画像自己テスト、ネスト深さ検査。
- NoSラジオの一時欠落→復帰→キー解除を自己テストで確認。
- 実際のNoS試合での瞬間的なRadioData欠落と音声漏れはベータテスト対象。
