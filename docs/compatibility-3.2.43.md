# TanukiBCL 3.2.43 互換チェックリスト

公式リリース: https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.43

- 各ボイスエフェクトの強さは利用者の個人設定で管理し、ロビー設定からは有効／無効を読む。
- 旧ロビー設定の強さは、個人設定がまだない場合だけ移行する。
- SNR・NoSと各アドオンの強さ設定とテスト対象は、対応するMOD・アドオンを検出した場合だけ表示する。
- エフェクトテストは強さ設定から独立した区画に表示する。
- WPF Releaseビルドと設定画面・音声ポリシーの自己テストで確認済み。実ゲームでの確認はベータテスト対象。

[3.2.42互換チェックリスト](compatibility-3.2.42.md)以前の資料は履歴です。
