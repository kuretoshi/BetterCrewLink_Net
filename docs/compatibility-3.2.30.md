# TanukiBCL 3.2.30 互換チェックリスト

公式リリース: https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.30

## 反映

- 3.2.29のAmong Us終了時修正を移植。NoS音声役職データにプレイヤー一覧がない場合、ゲーム状態の入口で空一覧に正規化し、NoS音声役職送信とホスト中継は欠落した一覧を送信対象外とする。
- 3.2.30の修正はElectron版の `registry.node` 同梱漏れ。WPF/.NET版にこの依存はない。代わりに.NET版が使用する `opus.dll` と `speexdsp.dll` の配布ZIP同梱を必須検査に追加した。
- 3.2.28までの音声・問い合わせ動作を維持。通話プロトコルの変更はない。

## 確認

- プレイヤー一覧欠落を模擬したゲーム終了、NoS音声役職送信、ホスト中継の自己テスト。
- Release/x64ビルド、ネスト深さ上限3、ZIP・インストーラーのネイティブ依存ファイルと展開ZIPからの起動検証。
- 実ゲーム終了時の再現確認はベータ利用者のフィードバック対象。
