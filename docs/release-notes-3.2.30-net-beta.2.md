# TanukiBCL.Net 3.2.30 β2

Windows x64向けベータ・プレリリースです。[β1](https://github.com/kuretoshi/BetterCrewLink_Net/releases/tag/v3.2.30-net-beta.1)の内容に加え、バージョン不一致通知やロビー警告が表示・解除された時に、コンパクト画面のヘッダーとプレイヤー一覧をウィンドウのリサイズなしで再レイアウトします。

通知の表示・解除による寸法変化をWPF自己テストで確認しました。実ロビーでの見え方は引き続きベータフィードバック対象です。

通常は `TanukiBCL.Net-Setup-3.2.30-net-beta.2.exe` を使用してください。持ち運び・アプリ内更新用ZIPもあります。インストーラーは未署名です。
