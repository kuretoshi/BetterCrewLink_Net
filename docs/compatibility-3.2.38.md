# TanukiBCL 3.2.38 互換チェックリスト

公式リリース: https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.38

- タヌキ丼0.1.0-β14のボイスジャミンガーに対応。次の会議だけ対象者を強制ミュート、または1.2 kHzのローパスで処理する。
- 会議中の全体ランダムピッチを話者ごとに適用する。設定秒数の経過・会議終了・試合終了・古いIPC状態の失効時には解除する。
- 手動ミュート・既存の聞こえる範囲・通常の音量設定を維持する。Web・モバイルへのホスト中継にも妨害状態を含める。
- 対象別のミュート、ローパス、ピッチ選択、会議終了時の復元、PID・時刻・不正データの検証、モバイル向け状態送信を自動テストで確認。複数人での新役職の実音声確認は未実施。
