# TanukiBCL.Net 3.2.41 β1

公式タヌキのベタクル3.2.41に合わせたWindows x64向けベータ・プレリリースです。

- 「ボイスエフェクト」をオーディオから独立した設定項目に移動しました。
- キノコカオス・変装、SNRジャンボ、NoSの役職・状態ごとに強さを調整できます。
- TOH4E／TOH4E_EMの参加者も、現在のロビーから「幽霊の声が聞こえる役職設定」を閲覧専用で開けるようにしました。ホストの編集制限は維持しています。
- Releaseビルドと設定画面の自己テストを実施しました。実ゲームでの確認はベータテスト対象です。

通常は `TanukiBCL.Net-Setup-3.2.41-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
