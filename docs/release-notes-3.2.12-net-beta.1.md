# TanukiBCL.Net v3.2.12-net-beta.1

タヌキのベタクル v3.2.12 の修正内容を.NET/WPF版へ反映した、Windows x64向けプレリリースです。完全互換版ではありません。

## 3.2.12から反映した変更

- **ラジオの声の届く範囲**: ラジオ使用中の声は、同じチームの生存者と幽霊にのみ届きます。ジャッカルのラジオも幽霊に届くようになりました。.NET版では近くのクルーにラジオの声が漏れる問題は以前から起きていませんでしたが、回帰テストを追加しました。
- **アバターの切り取り**: Hat・Visorが発話時の枠からはみ出さないよう、通常画面・オーバーレイとも枠と同じ円で切り取ります。
- **NoSのロビー表示**: Nebula on the ShipのSkin・Hat・Visor・色をロビーでもアバターに反映します。
- 相手へ通知するバージョンを`v3.2.12`に変更しました。

## メモリ使用量の削減

- NoSの`LoadedContents.json`を1件ずつ読み取り、一覧の全文をメモリに残さないようにしました。NoS起動中のメモリ使用量（Private Bytes）が手元の計測で約9 MiB減りました。
- NoSのSkin・Hat・Visor画像の保持量を最大約56 MiBから24 MiBに制限しました。スプライトシート全体ではなく、表示する1フレームだけを読み込みます。
- 帽子画像のキャッシュ上限を64 MiBから32 MiBにしました。多くのロビーを回る長時間の利用でも増え続けにくくなります。
- デバッグ画面の一覧ファイル表示は、画面を開いている間だけ読み込み、ファイルの更新時だけ再整形します。

メモリをさらに減らしたい場合は、設定の「ハードウェアアクセラレーション」をOFFにすると、手元の環境で約26 MiB減りました。描画はCPUで行うため、環境によっては動作が重くなります。

通常は `TanukiBCL.Net-Setup-3.2.12-net-beta.1.exe` を使用してください。持ち運び用とアプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーはデジタル署名されていません。

ロビーでのNoSコスチューム表示、幽霊へのジャッカルのラジオ、試合中のメモリ削減量はまだ実機で確認していません。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。パスワードやロビーの秘密情報は添付しないでください。
