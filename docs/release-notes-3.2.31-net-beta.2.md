# TanukiBCL.Net 3.2.31 β2

試合中の会議以外で、ゲーム内オーバーレイとベタクル画面の発話表示が一致しない問題を修正した、Windows x64向けベータ・プレリリースです。

- ゲーム内オーバーレイにもベタクル画面と同じ可聴判定を反映し、通常の近接会話では聞こえる範囲の相手だけが発話時に光るようにしました。
- コンパクトなゲーム内オーバーレイでも、聞こえない相手の発話だけで表示されないようにしました。会議中の発話判定は従来どおりです。
- ビルド、近距離・遠距離・接近・会議時の回帰テスト、ネスト検査を確認しました。実ロビーでの目視確認はベータテスト対象です。

通常は `TanukiBCL.Net-Setup-3.2.31-net-beta.2.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
