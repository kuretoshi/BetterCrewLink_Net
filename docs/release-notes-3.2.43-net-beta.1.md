# TanukiBCL.Net 3.2.43 β1

タヌキのベタクル3.2.43に合わせたWindows x64向けベータ・プレリリースです。

- 各ボイスエフェクトの強さを個人設定として保存し、ゲーム中も調整できるようにしました。以前のロビー設定値は初回起動時に引き継ぎます。
- 対応エフェクトを選んでマイクから試せる「エフェクトテスト」を独立した区画に設けました。
- シトラス感染時の設定名とスライダーの表示を整えました。
- 有効／無効は引き続きロビー設定で管理します。
- Releaseビルドと自己テストを実施しました。実ゲームでの確認はベータテスト対象です。

通常は `TanukiBCL.Net-Setup-3.2.43-net-beta.1.exe` を使用してください。持ち運び・アプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーは未署名です。
