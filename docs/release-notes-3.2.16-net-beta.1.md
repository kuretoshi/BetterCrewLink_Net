# TanukiBCL.Net v3.2.16-net-beta.1

公式[タヌキのベタクル v3.2.16](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.16)の主な変更を反映した、Windows x64向けベータ・プレリリースです。v3.2.15の無線マスク修正も含みます。

- NoSのインポスター無線とジャッカル無線を別チャンネルにし、既定のF/Gを設定画面から変更できます。同時押しでは最後のキーを優先し、離すと残るキーのチャンネルへ戻します。
- 送信チャンネルを相手へ通知し、送信者の`RadioData`にある受信者ビットだけで音声と発話表示の可否を決めます。マスク未取得中に通常の近距離音声へ漏れる経路も防ぎます。
- NoSのZIPコスチューム画像検索を整理し、同じカテゴリの画像を衣装ごとに繰り返し走査しないようにしました。ゲーム読取・画像・設定・音声ルールの回帰テストを実行し、変更箇所に制御構文のネスト深さ検査を追加しました。

**ベータ版の注意:** .NET版と公式3.2.16のNoS二重チャンネル実機通話、Web側のチャンネル分離はまだ検証できていません。公式版も送受信双方のPC更新が必要と案内しています。既存の深い.NETコード全体を3段以内に改修したわけではなく、今回の新規コードと変更箇所で深さを悪化させない検査です。

通常は `TanukiBCL.Net-Setup-3.2.16-net-beta.1.exe` を使用してください。持ち運び用とアプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーはデジタル署名されていません。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。
