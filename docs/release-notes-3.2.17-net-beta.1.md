# TanukiBCL.Net v3.2.17-net-beta.1

公式[タヌキのベタクル v3.2.17](https://github.com/kuretoshi/TanukiBCL/releases/tag/v3.2.17)の画面変更を取り込んだ、Windows x64向けベータ・プレリリースです。

- 人数が増えてもメイン画面のフッターを下部に表示し、プレイヤー一覧を画面幅に合わせて再配置・スクロールします。
- 問い合わせフォームを設定画面に移し、旧独立ウィンドウとフッターの起動ボタンを削除しました。送信時のサポートログ自動添付は維持しています。
- C#ソース全体（`src`・`tools`・`tests`）の制御構文ネストを3段以内に整理し、全体検査を追加しました。

ビルド、画面・コスチューム・問い合わせの自己テスト、音声ポリシー／処理、NoSスナップショット、ローカルサーバー再接続、ネスト検査を通過しました。公式3.2.17との実機相互通話とリサイズ時の実画面比較は未確認です。

通常は `TanukiBCL.Net-Setup-3.2.17-net-beta.1.exe` を使用してください。持ち運び用とアプリ内更新用の `TanukiBCL.Net-win-x64.zip` もあります。インストーラーはデジタル署名されていません。不具合は[GitHub Issues](https://github.com/kuretoshi/BetterCrewLink_Net/issues)へ報告してください。
